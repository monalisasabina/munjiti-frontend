# St Mary’s Munjiti Parish Website

![Node.js](https://img.shields.io/badge/Node.js-16+-green?style=flat-square&logo=node.js)
![npm](https://img.shields.io/badge/npm-8+-red?style=flat-square)

This is the official website for **St Mary’s Munjiti Parish**, an Anglican Church located in **Vihiga County, Western Kenya**.  
The website is designed to provide church members and visitors with information about church activities, announcements, projects, and a way to get in touch with the church.

---

## Project Overview

The goal of this project is to create a modern, easy-to-use church website that:

- Shares church notices and announcements
- Displays ongoing and completed church projects
- Provides basic information about the parish
- Allows congregants and visitors to contact the church
- Is easy to update by church administrators

---

## Main Features

- **Home Page**: Welcome message and church overview
- **About Page**: Information about the parish and its mission
- **Compassion Page**: Highlights church projects and community outreach
- **Contact Page**: Church contact details for visitors (no form yet)
- **Give Page**: Information on donations and giving to the church

## Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Navigate to the project folder
```bash
cd munjiti-frontend
```

3. Install dependencies: 
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```
